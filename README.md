# Clube Vermelho Amarelo

Quero criar um site para o meu clube, com as cores vermelho, amarelo e branco.

Tem que ter página início, notícias, futebol (equipas), modalidades, corporate (parceiros e patrocinios), multimedia, socios (informacoes gerais e lugar anual) e contactos.

Para além destas páginas, quero uma página padrão para a equipa inteira, em que apareçem as fotos dos jogadores com alguma informacao como idade, posicao e numero.

Depois, cada jogador, deve ter uma página dedicada para ele com as suas informacoes, fotos, dados pessoais.

As paginas devem contar com um CTA. Devem existir CTA's diferentes mediante as paginas, para fidelizar socio, incentivar a comprar lugar anual, subscrever newsletter para receber noticias.

Com um mega footer, e deve ter também um Hero na página inicial, que ocupe o browser todos quando faz refresh.

A página deve contar sempre também com um breadcrumb pequeno
